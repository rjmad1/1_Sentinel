# ADR-003: Lightweight Property Graph Engine Architecture

## Status
Accepted (Updated)

## Context
Infrastructure topologies require reactive node-link traversal. Local-first deployment constraints require zero external graph daemon dependencies on single-node installations.

## Decision
Adopt `@xyflow/react` with `Graphology` in the presentation tier and PostgreSQL recursive common table expressions (CTEs) in the relational backend tier as the primary graph engine.

## Consequences
- Zero external JVM/JanusGraph daemon overhead for desktop and single-node installations.
- Fast interactive client-side graph rendering and dependency path propagation.
