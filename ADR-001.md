# ADR-001: Fleet-Capable Architecture with Single-Node V1 Deployment

## Status
Accepted

## Context
We need to support running assessments on developer workstations locally without requiring massive cloud/server dependencies. However, the enterprise requires central fleet management.

## Decision
Design the domain models and events to support Site/Tenant hierarchies from inception. The V1 implementation will run locally (IndexedDB/SQLite) but use the same domain event boundaries and schema contracts that V2 will deploy into a cluster.

## Consequences
- Single-machine usage has minimal overhead.
- Simple upgrade path to PostgreSQL and NATS fleet coordination in V2.
